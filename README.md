# mentorQuiz

## Project Overview
MentorQuiz is a Flutter-based mobile application designed to facilitate learning through interactive quizzes. The app aims to provide an engaging platform for users to test and enhance their knowledge across various subjects.

## Features
- User authentication and profile management
- Interactive quiz interface
- Real-time scoring and progress tracking
- Multiple quiz categories
- Performance analytics
- Leaderboard system

## Tech Stack
- Flutter (Frontend Framework)
- Dart (Programming Language)
- Firebase (Backend & Authentication)
- Provider (State Management)

## Getting Started

### Prerequisites
- Flutter SDK (latest version)
- Android Studio / VS Code
- Git
- A Firebase account (for backend services)

### Installation
1. Clone the repository
   ```bash
   git clone https://github.com/yourusername/mentorQuiz.git
   ```
2. Navigate to the project directory
   ```bash
   cd mentorQuiz
   ```
3. Install dependencies
   ```bash
   flutter pub get
   ```
4. Configure Firebase
   - Create a new Firebase project
   - Add your Firebase configuration files
   - Enable required Firebase services

### Running the Application
1. Ensure you have a device connected or emulator running
2. Run the app using:
   ```bash
   flutter run
   ```
